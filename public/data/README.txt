HYG nearby-star subsets

Adapted from HYG Stellar Database v4.0 by David Nash / Astronexus:
https://github.com/astronexus/HYG-Database/tree/main/hyg/CURRENT
Licensed under Creative Commons Attribution-ShareAlike 4.0 International:
https://creativecommons.org/licenses/by-sa/4.0/

The source CSV was filtered to positive distances of at most 50 parsecs and valid coordinate ranges, split into an inner subset (0–20 pc) and an optional outer shell (>20–50 pc), reduced to selected columns, given fallback display names, sorted and converted to JSON. Both adapted subsets are also licensed CC BY-SA 4.0. See the project README and scripts/extract-hyg.py for source details and reproduction.

Gaia DR3 local 1,000,000-source subset

© ESA/Gaia/DPAC, CC BY-SA 3.0 IGO:
https://creativecommons.org/licenses/by-sa/3.0/igo/
Adapted from azuregroove/galaxie-data (selection, coordinates, quantization, tiles):
https://github.com/azuregroove/galaxie-data/tree/59fcf5d6cf3103f6d9a5ca91f4784bbd07d9c17d
Further selected and repacked by this project, under the same licence. The source is
an incomplete, biased 100–500 pc inverse-parallax selection, not a whole-galaxy map.
See gaia-dr3-1m.json, the project README and scripts/prepare-gaia.py for selection,
provenance, citation and the full Gaia acknowledgement.
